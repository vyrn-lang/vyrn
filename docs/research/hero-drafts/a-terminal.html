vyrn — a compiled language

One program.
Three backends.
Identical bytes.

The interpreter, the native binary and the wasm module answer with the same stdout, the same stderr and the same exit code. Floating point included.

$ curl -fsSL vyrn.dev/install.sh | sh
01

Parity is measured, not claimed

The harness runs every example on all three backends and compares the bytes. Divergences: 0.

02

Types carry rules, not just shapes

A validated type rejects a bad constant while it compiles. When it cannot prove the value, it generates the check.

03

No collector, and no ownership puzzle

Ownership is declared. Memory is reclaimed at points you can name.
