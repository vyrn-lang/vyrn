#### A stored function value passed to a higher-order function is its target (2026-09-25, `m7-fnval2`)
RFC-0125, milestone M7.
Decision: the lead's. The track takes the second function-value group of the tail census, less the two `defer` bodies #516 took. The core names a stored `fn` value handed to a `fn`-typed parameter `Target::Value` and forwards the value after the call's own arguments, as a lambda target's captures are forwarded. `specialize` forwards a Value-bound parameter that a body passes on. The emitter binds such a parameter to its signature's dispatcher, with the value as the one capture (`core_dispatch`), as the arm's `resolve_fn_arg` does. `core_call` registers the dispatcher before it names the instance.
