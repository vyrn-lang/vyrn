#### A map tally is a rebuild row, with the key the caller's (2026-09-25, `m7-mapcall`)
RFC-0125, milestone M7.
Decision: the lead's. The track took `@tally`, then `@tallyBytes`, one commit each, after `@remove` (`0125-m7-mapcall.md`). Both join `Spec::Rebuilds`: a receiver the call rebuilds in place and the store after it puts back. The row states who owns the key. `@tally` reads its key and never takes it, and a miss stores a copy the map owns. `@tallyBytes` reads its bytes, and a miss stores a String it builds, which the map owns. So the caller releases its own key on both paths. The kernel judges the prelude's capabilities as stated (the map `consume`d and stored back, the key and the count `read`), and its answer did not move.
