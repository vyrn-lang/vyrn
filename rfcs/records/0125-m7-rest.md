#### A move takes the moved name's place when no store can follow it (2026-09-25, `m7-rest`)
RFC-0125, milestone M7.
Decision: `core_renames` refused a move whenever the body stored into the moved name anywhere. A store before the move is part of the value that moves, so only a store that can run after it refuses. `core_after` names those rows: the later siblings of the `let` and of every statement around it, or the whole body where a loop holds the `let`. The lead's brief (M7 decision #453: ask a name for its place); the rule is `core_renames`' alone.
